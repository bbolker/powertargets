## powertargets

Rethinking power tests from a clarity standpoint.

Maybe start from [this quarto file](powertargets.qmd), rendered [here as a pdf](outputs/powertargets.pdf). On Unix (Linux or MacOS), you should be able to see the HTML by cloning the repo and saying `make Makefile` followed by `make powertargets.html.go`.

If you clone the repo, you should also be able to try the shiny app (cleverly named `app.R`)

If you get deprecation warnings about `aes_string`, make sure you have `directlabels` version >= 2026.4.21
